ProgramlamaTemelleri / Hafta1 · Hazırlık

1. hafta · Program yazmaya hazırlık

Bu hafta: problemi algoritmaya, algoritmayı akış şemasına ve C# koduna çevirmek; Visual Studio'da ilk programı yazıp çalıştırmak, ekrana yazmak ve klavyeden okumak.

Problem çözme adımları

Bilgisayar ne yapacağını kendi bilmez; her adımı bizim söylememiz gerekir. Bu yüzden kod yazmadan önce çözüm planlanır:

  1. Problemi anla: girdi ne, çıktı ne olmalı? (Girdi: iki sayı. Çıktı: toplamları.)
  2. Algoritmayı kur: çözümü sıralı adımlar hâlinde yaz.
  3. Akış şemasını çiz ya da sözde kodu yaz: adımları şekille ya da yarı-kodla düzenle.
  4. Kodla: algoritmayı C# diline çevir.
  5. Derle ve çalıştır: derleyici yazım hatalarını bulur, sonra program çalışır.
  6. Test et, hata ayıkla: farklı girdilerle dene, yanlış sonucu düzelt.

Algoritma

Algoritma, bir problemi çözmek için izlenen, sırası belli, sonlu sayıda ve açık adımlardır. Yemek tarifi de bir algoritmadır. İyi bir algoritma:

  • Sonludur: belli bir adımda biter.
  • Açık ve kesindir: her adım tek anlama gelir ("biraz tuz" değil, "1 çay kaşığı tuz").
  • Girdisi ve çıktısı vardır: veri alır (ya da almaz), en az bir sonuç üretir.
  • Uygulanabilirdir: her adım gerçekten yapılabilir.
Algoritma · iki sayının toplamı

  2. Birinci sayıyı oku (a)
  3. İkinci sayıyı oku (b)
  4. toplam ← a + b
  5. toplam'ı ekrana yaz
  6. Bitir

Sözde kod belli bir dile bağlı değildir; Türkçe komutlarla kodun iskeletini kurar.

Akış şeması

Akış şeması algoritmayı standart şekillerle çizer. Okları takip ederek programın hangi sırayla ilerlediğini görürsün. Şekillerin anlamı:

Başla / BitirElips (oval). Her algoritmada bir başlangıç, en az bir bitiş.
Girdi / ÇıktıParalelkenar. Oku (klavye), Yaz (ekran).
İşlemDikdörtgen. Hesaplama, atama: toplam = a + b.
KararEşkenar dörtgen (baklava). Koşul; Evet / Hayır iki çıkış.
Döngü (hazırlık)Altıgen. Bazı kitaplar for döngüsünü bununla çizer.
Akış yönüOk. Adımların sırasını gösterir.
BağlantıDaire. Şema bölünürse parçaları birleştirir.
Sınavda akış şeması çizerken

Bir Başla ve en az bir Bitir; okuma ve yazma paralelkenar, hesap dikdörtgen, koşul baklava (iki çıkışını Evet / Hayır diye etiketle). Oklar çapraz kesişmesin; döngüde ok karar kutusuna geri döner.

Alıştırma: adımları sırala

C# programı nasıl çalışır?

  1. Program.cskaynak kod (senin yazdığın)

Hata yoksa ortaya IL (ara dil) kodu çıkar; .NET'in çalışma ortamı CLR, bu kodu çalışırken (JIT) işlemcinin anlayacağı makine koduna çevirir.

2. hafta · Değişkenler ve sabitler

Bu hafta: değişken tanımlama ve adlandırma, veri türleri, const sabitler, tür dönüşümleri ((int), Convert, Parse), Türkçe Windows'taki virgül-nokta tuzağı ve çıktıyı biçimlendirme.

Değişken nedir?

Değişken, bellekte adı, türü ve değeri olan bir kutudur. Tür, kutuya ne konabileceğini ve bellekte ne kadar yer tutacağını belirler. Tanımlama kalıbı: tür ad = değer;

int yas = 20;          // tanımla ve ilk değeri ver
string ad = "Ayşe";
yas = 21;              // değeri sonradan değişebilir (tür değişmez)
int a = 3, b = 4;      // aynı türden birden çok değişken
int toplam;            // değer vermeden tanımla...
toplam = a + b;        // ...kullanmadan önce mutlaka değer ata
Değer almamış değişken kullanılamaz

int x; Console.WriteLine(x); derlenmez: CS0165 (atanmamış yerel değişken). C# yerel değişkene kendiliğinden 0 vermez; döngüde toplam tutarken int toplam = 0; diye başlatmanın sebebi bu.

2. haftadan akılda kalsın
  • Tanımlama: tür ad = değer; · ad harf ya da _ ile başlar, boşluk ve anahtar kelime olmaz.
  • Ondalık sabit soneksizse double: float için f, decimal için m.
  • (int) kesri atar, Convert.ToInt32 yuvarlar (2,5 → 2). ReadLine metnini Convert ya da Parse ile sayıya çevir.
  • Türkçe Windows'ta girişte ondalık virgül: 2.5 yazılırsa 25 okunur.
  • const değişmez (CS0131). Atanmamış değişken kullanılmaz (CS0165).

ProgramlamaTemelleri / Hafta4 · if-else

4. hafta · Karar ve kontrol deyimleri: if

Bu hafta: if, if-else, else if merdiveni, mantıksal operatörlerle koşul, iç içe if ve üçlü operatör ?:. Programın bir koşula göre farklı yollara ayrılması.

if ve if-else

if (koşul)
{
    // koşul true ise çalışır
}
else
{
    // koşul false ise çalışır (else isteğe bağlı)
}

Koşul bool bir ifadedir: true ya da false üretmelidir. Bloklardan yalnızca biri çalışır; ikisi birden asla. Blokta tek deyim varsa { } yazılmayabilir, ama hatayı önlemek için her zaman yazmak iyi alışkanlıktır.

else if merdiveni

Koşulda mantıksal operatörler

İç içe if

Üçlü operatör: ?:

Süslü parantez ve noktalı virgül tuzakları

int x = 3;
if (x > 5)
    Console.WriteLine("büyük");
    Console.WriteLine("bitti");  // girintiye aldanma: if'e ait değil, hep çalışır

if (x == 5);                      // ; if'in gövdesini bitirdi (boş deyim)
{
    Console.WriteLine("beş");     // x 3 olduğu hâlde çalışır! (uyarı CS0642)
}

if (x = 5) { }                    // derlenmez: CS0029, == olmalı

Süslü parantez yoksa if yalnızca ilk deyimi kapsar; C#'ta girinti anlam taşımaz. if (…); yazınca noktalı virgül boş bir deyimdir ve koşulun gövdesi olur; alttaki blok koşulsuz çalışır. Üçünü de Derlenir mi? kartlarında gerçek sonuçlarıyla dene.

4. haftadan akılda kalsın
  • if (koşul) { } else { }: bloklardan yalnız biri çalışır. Koşul bool olmalı.
  • else if zincirinde ilk doğru koşul kazanır; koşul sırası sonucu değiştirir.
  • Birden çok şart: && (hepsi), || (en az biri), ! (değil).
  • İç içe if: dıştaki doğruysa içteki sınanır.
  • değişken = koşul ? a : b; kısa if-else.
  • Tuzaklar: if (x = 5) derlenmez; if (…); gövdeyi boşaltır; süslü parantezsiz if yalnız tek deyimi kapsar.
ProgramlamaTemelleri / Hafta5 · switch

5. hafta · Karar ve kontrol deyimleri: switch-case

Bu hafta: switch-case, break ve default, aynı bloğu paylaşan case'ler, metinle switch, if ile switch'in karşılaştırılması ve yeni C#'ın switch ifadesi. Hafta sonunda if ve switch'i birlikte kullanan örnekler.

switch-case yapısı

switch (ifade)
{
    case değer1:
        // ifade == değer1 ise
        break;
    case değer2:
    case değer3:
        // değer2 ya da değer3 ise
        break;
    default:
        // hiçbiri tutmazsa
        break;
}
  • switch parantezindeki değeri sırayla case değerleriyle eşitlik için karşılaştırır.
  • Eşleşen case'in deyimleri çalışır; break switch'ten çıkarır.
  • Hiçbir case tutmazsa default çalışır. default zorunlu değildir ama iyi alışkanlıktır.

6. hafta · Döngü kontrol deyimleri: for

Bu hafta: döngü kavramı, for döngüsünün çalışma sırası, sayaç ve toplayıcı kalıpları, faktöriyel, çarpım tablosu, N notun ortalaması ve izleme tablosu çıkarmak.

Döngü nedir?

Aynı işi 100 kez yapmak için 100 satır yazılmaz; işi bir kez yazıp tekrarlatırız. Döngüler bir koşul doğru olduğu sürece bir bloğu tekrar tekrar çalıştırır. C#'ta dört döngü var: for, while, do-while ve foreach.

for döngüsü

for (başlangıç; koşul; artırma)
{
    // gövde: koşul true olduğu sürece tekrar eder
}

for (int i = 1; i <= 5; i++)
{
    Console.WriteLine(i);
}
Çalışma sırası
  1. başlangıç (int i = 1) yalnız bir kez çalışır.
  2. koşul (i <= 5) sınanır; false ise döngü biter.
  3. gövde çalışır.
  4. artırma (i++) çalışır, sonra 2. adıma dönülür.

Adım değeri ve geri sayım

Toplayıcı (akümülatör) kalıbı

Çarpım biriktirme: faktöriyel

Çarpım tablosu

Üs alma

Örnek: N notun ortalaması, en yüksek ve en düşük

for tuzakları

for (int i = 0; i < 3; i++);      // ; döngünün gövdesi oldu (boş deyim)
{
    Console.WriteLine("Merhaba");   // yalnız bir kez çalışır
}

for (int i = 1; i < 10; i++) { }   // 1..9  → 9 tur (10 dahil değil)
for (int i = 1; i <= 10; i++) { }  // 1..10 → 10 tur

for (int i = 10; i > 0; i++) { }   // i büyüdükçe koşul hep true: sonsuz döngü

int toplam;                        // değer verilmedi...
for (int i = 1; i <= 3; i++)
    toplam += i;                   // ...CS0165: atanmamış değişken
6. haftadan akılda kalsın
  • for (başlangıç; koşul; artırma): başlangıç bir kez; koşul her turdan önce; artırma her turdan sonra.
  • Tur sayısını hesapla: i = 1; i <= n → n tur; i = 0; i < n → n tur; i = 1; i < n → n - 1 tur.
  • Toplayıcı 0'dan, çarpım 1'den başlar ve döngüden önce tanımlanır.
  • Döngü değişkeni (int i) döngü dışında yoktur.
  • İzleme tablosu: her sınamada değişkenlerin değeri; son satırda koşul false.
