CppTemelleri / Hafta1 · Hazırlık

1. hafta · Program yazmaya hazırlık

Bu hafta: problemi algoritmaya, algoritmayı akış şemasına ve C++ koduna çevirmek; ilk programı yazıp derlemek, cout ile ekrana yazmak, cin ve getline ile klavyeden okumak.

Problem çözme adımları

Bilgisayar ne yapacağını kendi bilmez; her adımı bizim söylememiz gerekir. Bu yüzden kod yazmadan önce çözüm planlanır:

  1. Problemi anla: girdi ne, çıktı ne olmalı? (Girdi: iki sayı. Çıktı: toplamları.)
  2. Algoritmayı kur: çözümü sıralı adımlar hâlinde yaz.
  3. Akış şemasını çiz ya da sözde kodu yaz: adımları şekille ya da yarı-kodla düzenle.
  4. Kodla: algoritmayı C++ diline çevir.
  5. Derle ve çalıştır: derleyici yazım hatalarını bulur, sonra program çalışır.
  6. Test et, hata ayıkla: farklı girdilerle dene, yanlış sonucu düzelt.

Algoritma

Algoritma, bir problemi çözmek için izlenen, sırası belli, sonlu sayıda ve açık adımlardır. Yemek tarifi de bir algoritmadır. İyi bir algoritma:

  • Sonludur: belli bir adımda biter.
  • Açık ve kesindir: her adım tek anlama gelir ("biraz tuz" değil, "1 çay kaşığı tuz").
  • Girdisi ve çıktısı vardır: veri alır (ya da almaz), en az bir sonuç üretir.
  • Uygulanabilirdir: her adım gerçekten yapılabilir.
Algoritma · iki sayının toplamı
  1. Başla
  2. Birinci sayıyı oku (a)
  3. İkinci sayıyı oku (b)
  4. toplam ← a + b
  5. toplam'ı ekrana yaz
  6. Bitir

2. hafta · Değişkenler ve sabitler

Bu hafta: değişken tanımlama ve adlandırma, veri türleri ve boyutları, const ve #define sabitleri, tür dönüşümleri, cout'un ondalık gösterimi, iomanip ile biçimlendirme ve taşma.

Değişken nedir?

Değişken, bellekte adı, türü ve değeri olan bir kutudur. Tür, kutuya ne konabileceğini ve bellekte ne kadar yer tutacağını belirler. Tanımlama kalıbı: tür ad = değer;

int yas = 20;          // tanımla ve ilk değeri ver
string ad = "Ayse";   // #include <string>
yas = 21;              // değer sonradan değişebilir (tür değişmez)
int a = 3, b = 4;      // aynı türden birden çok değişken
int c(5);              // C++'ın diğer yazılışları
int d{5};              // süslü parantez (C++11): daraltmaya izin vermez
int toplam;            // değer vermeden tanımla: içinde çöp değer var!
Değer verilmemiş değişken hata vermez

C++'ta int toplam; diye tanımlanan yerel değişkenin içinde rastgele bir çöp değer vardır ve derleyici bunu çoğu zaman hata saymaz. Döngüde toplam += i yaparsan sonuç rastgele çıkar. Adım adım izde bu değişkenler ? görünür. Kural: her değişkene tanımlarken değer ver (int toplam = 0;).

5. hafta · Karar ve kontrol deyimleri: switch-case

Bu hafta: switch-case, break ve default, break unutulunca aşağı düşme, aynı bloğu paylaşan case'ler, char ile switch, case içinde değişken tanımlama ve if ile switch'in karşılaştırılması.

switch-case yapısı

switch (ifade)
{
    case deger1:
        // ifade == deger1 ise
        break;
    case deger2:
    case deger3:
        // deger2 ya da deger3 ise
        break;
    default:
        // hiçbiri tutmazsa
        break;
}
  • switch parantezindeki değeri sırayla case değerleriyle eşitlik için karşılaştırır.
  • Eşleşen case'ten başlanır ve break görülene kadar aşağıya doğru çalışılır.
  • Hiçbir case tutmazsa default çalışır. default zorunlu değildir ama iyi alışkanlıktır.
  • Case değerleri sabit olmalı ve tekrar etmemeli (duplicate case value).
  • Yalnız tam sayı ve karakter (int, char, bool, enum) kullanılabilir: string ve double ile switch derlenmez.

6. hafta · Döngü kontrol deyimleri: for

Bu hafta: döngü kavramı, for döngüsünün çalışma sırası, sayaç ve toplayıcı kalıpları, faktöriyel, çarpım tablosu, N notun ortalaması ve izleme tablosu çıkarmak.

Döngü nedir?

Aynı işi 100 kez yapmak için 100 satır yazılmaz; işi bir kez yazıp tekrarlatırız. Döngüler bir koşul doğru olduğu sürece bir bloğu tekrar tekrar çalıştırır. C++'ta for, while, do-while ve C++11'den beri metin gibi koleksiyonlar için aralık tabanlı for vardır.

for döngüsü

for (başlangıç; koşul; artırma)
{
    // gövde: koşul true olduğu sürece tekrar eder
}

for (int i = 1; i <= 5; i++)
{
    cout << i << endl;
}
Çalışma sırası
  1. başlangıç (int i = 1) yalnız bir kez çalışır.
  2. koşul (i <= 5) sınanır; false ise döngü biter.
  3. gövde çalışır.
  4. artırma (i++) çalışır, sonra 2. adıma dönülür.

Adım değeri ve geri sayım

Toplayıcı (akümülatör) kalıbı

Çarpım biriktirme: faktöriyel

Çarpım tablosu

Üs alma

Örnek: N notun ortalaması, en yüksek ve en düşük

for tuzakları

for (int i = 0; i < 3; i++);      // ; döngünün gövdesi oldu (boş deyim)
{
    cout << "Merhaba" << endl;    // yalnız bir kez çalışır
}

for (int i = 1; i < 10; i++) { }   // 1..9  → 9 tur (10 dahil değil)
for (int i = 1; i <= 10; i++) { }  // 1..10 → 10 tur

for (int i = 10; i > 0; i++) { }   // i büyüdükçe koşul hep true: sonsuz döngü

int toplam;                        // değer verilmedi: çöp değer!
for (int i = 1; i <= 3; i++)
    toplam += i;                   // derlenir ama sonuç rastgele
6. haftadan akılda kalsın
  • for (başlangıç; koşul; artırma): başlangıç bir kez; koşul her turdan önce; artırma her turdan sonra.
  • Tur sayısını hesapla: i = 1; i <= n → n tur; i = 0; i < n → n tur; i = 1; i < n → n - 1 tur.
  • Toplayıcı 0'dan, çarpım 1'den başlar ve döngüden önce değer verilerek tanımlanır.
  • Döngü değişkeni (int i) döngü dışında yoktur. ^ üs değildir.
  • İzleme tablosu: her sınamada değişkenlerin değeri; son satırda koşul false.
