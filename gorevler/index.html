görevler yükleniyor…

›_ ilk kurulum · 5 dakika

Unutma, hatırlatırım.

Görevlerini buraya ya da Telegram'a doğal Türkçeyle yaz: “yarın 14:00 veritabanı ödevi”. Zamanı gelince telefonuna Telegram'dan mesaj gelir, sabah ve akşam günün özeti düşer.

Görevler herkese açık site deposunda değil, yalnız senin görebildiğin ayrı bir depoda durur. Hatırlatmaları GitHub Actions gönderir; sunucu ya da ücret yok.

  1. Gizli veri deposunu aç

    Adı gorev-verisi olsun ve Private seçili kalsın. Başka bir şey eklemene gerek yok.

    GitHub'da depo oluştur ↗

  2. Erişim anahtarı oluştur

    Açılan sayfada ad, süre (1 yıl) ve Contents: Read and write izni hazır gelir. Senin yapacağın:

    • Repository access → Only select repositories → gorev-verisi
    • En altta Generate token → çıkan github_pat_… anahtarını kopyala

    Anahtar yalnız gorev-verisi deposuna dokunabilir; site koduna ya da diğer depolarına erişemez.

    Anahtar oluştur ↗

  3. Bu tarayıcıyı bağla

    Anahtar yalnız bu tarayıcıda saklanır ve yalnız api.github.com'a gönderilir.

  4. Telegram'ı bağla

    Bağlandıktan sonra sayfada bot kurulumu ve eşleştirme adımları açılır: BotFather'dan bot al, iki sır ekle, kodu bota gönder.

Görevler

Telegram hatırlatmalarını aç

  1. Telegram'da @BotFather'ı aç → /newbot → bir ad ve sonu bot ile biten bir kullanıcı adı ver → verdiği token'ı kopyala.
  2. Site deposuna iki sır ekle: Settings → Secrets → Actions ↗
    TELEGRAM_BOT_TOKEN = BotFather'ın verdiği token
    GOREV_TOKEN = bu sayfaya girdiğin erişim anahtarının aynısı
  3. Hatırlatıcı 5 dakikada bir kendiliğinden çalışır. Beklemek istemezsen Actions → Görev hatırlatıcısı → Run workflow ↗
    Bot henüz çalışmadı
  4. Eşleştir: kodu üret, bota gönder.
    Bota gönder: Telegram'da aç ↗
